# GitHub 작업과 PR

| 상위 이슈 | 서브 이슈와 인수 기준 | 브랜치 |
| --- | --- | --- |
| 설계 및 저장소 | 기능·데이터 계약 작성 / 공급자 승인과 제한 검증 / 독립 로컬 실행 확인 | docs/mvp-spec |
| 인증 및 공고 API | Auth 세션과 Bearer 검증 / 소유자 RLS와 두 계정 검증 / 수동 중복과 검색 필터 검증 | feat/catalog |
| 검색 및 지원 관리 | 로그인·검색·등록 UI / 즐겨찾기·4개 상태·메모·태그·마감일 / 반응형 UI와 새로 로그인 후 저장 검증 | feat/tracking-ui |
| 고용24 공식 연동 | XML 합성 테스트 / 제한 및 중복 실행 / 출처 표시 / 발급 및 보존 조건 확인 후 실호출 | feat/work24 |
| 검증 및 릴리스 | 격리 DB 통합 테스트 / Preview에서 전체 사용자 흐름 / Production 승인 확인 | feat/release-verification |

PR은 설계 → API → UI → 고용24 → 검증 순으로 검토한다. 각 PR에 상위 및 서브 이슈, 실제 검증 결과와 환경 변수를 연결한다. 커밋 메시지는 제목 한 줄, 빈 줄, 변경 사항 불릿 3~4개를 사용한다.
